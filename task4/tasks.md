## Крупные задачи по системам

### 1. Микросервис ставок
- Реализовать подписку на события изменения ставок из очереди АБС
- Настроить кэширование ставок в Redis
- Организовать генерацию CSV-файла (UTF‑8, `;`) и загрузку в S3
- Добавить endpoint `/rates/csv-url` для выдачи presignedURL
- Отправлять письмо на SMTP при получении новых ставоки

### 2. Внутренний кол‑центр
- Интегрировать вызов API `/rates` для получения ставок
- Интегрировать вызов API `/rates/csv-url` для получения ссылки на CSV
- Разработать UI для отображения ставок и скачивания CSV
- Настроить локальный кэш последних ставок в клиентском приложении

### 3. Email‑сервис
- Настроить SMTP: создать учётные записи, лимиты и политики безопасности
- Разработать HTML и текстовые шаблоны писем с метаданными presignedURL

### 4. Партнёрский кол‑центр
- Организовать процесс автоматического импорта CSV: загрузку по presignedURL и парсинг данных
