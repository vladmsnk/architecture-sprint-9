### <a name="_qmphm5d6rvi3"></a>**Решение**

1) [Диаграмма контекстов](context.puml)
2) [Диаграмма контейнеров](container.puml)

Доработанный алгоритм доставки ставок партнёру через рассылку presignedURL
1.	Получение и кеширование ставок
•	Микросервис по расписанию (Cron) запрашивает свежие ставки из АБС.
•	Сохраняет их в Redis (для быстрого доступа внутреннего кол‑центра) и одновременно генерирует CSV-файл, который загружает в S3
2.	Генерация и хранение presignedURL
•	После успешной загрузки в S3 микросервис сразу же формирует для этого файла presignedURL
3.	Доступ внутреннего кол‑центра
•	Операторы CRM запрашивают /rates, получают JSON напрямую из Redis.
•	При необходимости CRM делает запрос /rates/csv-url, получает текущий presignedURL и отображает его в интерфейсе.
4.	Рассылка presignedURL партнёру
•	Каждый раз после генерации нового presignedURL микросервис отправляет email на заранее согласованный адрес партнёрского кол‑центра.
•	Письмо содержит:
•	Ссылку на скачивание (presignedURL).
•	Метаданные: дата и время генерации файла, время истечения ссылки.
•	Для отправки письма микросервис использует свой SMTP‑клиент или интеграцию с почтовым сервисом.
5.	Получение файла партнёром
•	Партнёрский кол‑центр просто проверяет почту и кликает по ссылке — браузер получает CSV без дополнительных вызовов API или SFTP.

### <a name="_bjrr7veeh80c"></a>**Альтернативы**

* **ETL‑сервис и очередь**: потребует поддержки дополнительной технологии;

**Недостатки, ограничения, риски**

1. Письма с presignedURL могут задерживаться в очередях SMTP или попадать в спам-фильтры, из‑за чего партнёр получит ссылку с опозданием или вообще не получит её вовремя.
2.	Риск утечки и отсутствие контроля над ссылкой
Любой, кто получит письмо, может переслать presignedURL третьим лицам и скачать файл до истечения срока действия — отозвать доступ нельзя без удаления самого объекта из S3.
3.	Невозможность полноценной автоматизации
Партнёрский кол‑центр вынужден вручную или через собственные email‑боты парсить письма и кликать по ссылкам. Это неудобно при частых обновлениях и не гарантирует стабильный автоматический процесс.
